# RetailPulse 360 — Customer Growth, Churn & Segmentation Analytics

A portfolio-grade end-to-end data analytics case study for a fictional U.S. e-commerce company.

## Business objective
Leadership wants one analytics system that answers:
1. What drives revenue, profit, conversion, refunds and retention?
2. Which customers are at risk of churning in the next 90 days?
3. What meaningful customer segments exist for marketing and retention?
4. Which channels/products/regions deserve more attention?
5. What actions should leadership take based on the evidence?

## Portfolio stack
- SQL: data validation, joins, KPI queries, cohort/RFM analysis
- Python: pandas, NumPy, matplotlib, scikit-learn
- BI: Power BI or Tableau
- Supervised ML: churn classification
- Unsupervised ML: customer segmentation (K-Means, plus validation)
- Git/GitHub: reproducible repository, README, documentation

## Recommended final deliverables
- Executive dashboard
- SQL analysis scripts
- EDA notebook
- Churn prediction notebook
- Customer segmentation notebook
- Business recommendations
- Final README with screenshots and measurable findings

## Important
All data in this repository is synthetic and created for portfolio practice. It does not represent real customers or a real company.
